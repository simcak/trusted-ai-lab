# pii-cz

> Připravuje se ve **fázi 1**. Zatím jen místo ve struktuře repa, bez kódu.

Detekce a pseudonymizace českých osobních údajů (rodné číslo, IČO/DIČ, bankovní účet, IBAN,
telefon, e-mail, PSČ, adresa, jména) s validací kontrolních součtů. Režimy `redact`,
`pseudonymize` a `reversible`. Knihovna bude publikovatelná na npm a používají ji moduly
Agent a Lokálně.
