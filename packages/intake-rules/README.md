# intake-rules

> Připravuje se ve **fázi 2**. Zatím jen místo ve struktuře repa, bez kódu.

Pravidlový engine pro modul Intake, bez LLM. Každé pravidlo `{ id, when, effect, rationale, reference }`.
Doporučí vzor (no-ai / klasický software / ML / RAG / agent / HITL), požadované kontroly,
orientační kategorii AI Act a odhad nákladů. Unit test pro každé pravidlo i předvolbu.
